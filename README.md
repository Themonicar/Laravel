# 3D Interactive Scene

A beautiful, interactive 3D visualization built with Three.js featuring dynamic shapes, lighting effects, and smooth animations.

## Features

- **Multiple 3D Shapes**: Switch between cube, sphere, torus, and cone
- **Interactive Controls**: Drag to rotate, scroll to zoom
- **Dynamic Lighting**: Animated point lights and directional lighting
- **Color Customization**: Change object colors with preset options
- **Particle System**: Floating particles for ambient effect
- **Responsive Design**: Works on desktop and mobile devices
- **Smooth Animations**: Toggle automatic rotation on/off

## How to Use

1. Open `index.html` in a web browser
2. Use the control panel to:
   - Change shapes (Cube, Sphere, Torus, Cone)
   - Toggle rotation animation
   - Change colors (Blue, Pink, Cyan, Green)
3. Interact with the scene:
   - **Drag** with mouse to rotate the object
   - **Scroll** to zoom in/out
   - **Touch** on mobile devices to rotate

## Technologies

- Three.js (r128) - 3D graphics library
- HTML5 Canvas
- CSS3 with modern gradients and effects
- Vanilla JavaScript
